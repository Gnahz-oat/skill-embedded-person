# 嵌入式之人

Codex skill：在嵌入式软件、固件和驱动任务中，先据实分析与报告修改方案，获得明确授权后才做获批范围内的最小修改与验证。

安装目录：`~/.codex/skills/embedded-person/`。Codex 界面显示名为“嵌入式之人”；内部调用标识为 `$embedded-person`。

新功能开发：先只读检查相关实现，再一次问一个仍影响实现的关键问题；信息足够时给出修改方案并等待授权。

项目接续：每个嵌入式项目根目录使用本地 `CODEX_PROGRESS.md`。新聊天进入项目时读取；获批改动后更新一页内的当前状态与验证结果。Git 项目用仓库本地排除规则避免提交该文件；首次创建须先列入修改方案并获授权。

更新时修改 `SKILL.md`（工作规则）或 `agents/openai.yaml`（显示信息），并同步到本地安装目录。README 仅用于查阅，不作为执行指令。
